Windows Event Viewer – Security Log Analysis

1. Project Overview

Windows Event Viewer is a built-in Windows utility used to monitor and investigate system, application and security activities through event logs.
This project focuses on analysing Windows Security logs to understand authentication activities, privileged sessions and process-related events from a SOC analyst’s perspective.

2. Objective

* Understand Windows Event Viewer.
* Identify important Windows Security Event IDs.
* Investigate successful and failed login attempts.
* Understand privileged account activity.
* Learn how Windows logs support security monitoring and incident investigation.

3. Tools Used

* Windows Event Viewer
* Windows Operating System

4. Types of Windows Logs

Application: Records events generated by applications, including errors and crashes.

Security: Records security-related activities such as successful logins, failed logins and account management events.

System: Records operating system events such as startup, shutdown, driver and service issues.

Forwarded Events: Stores events collected from other computers through Windows Event Forwarding.

Administrative Events: A Custom View that displays critical events, errors and warnings from multiple logs.

5. Windows Security Event IDs

Event ID	Description
4624	Successful Logon

4625	Failed Logon

4634	Logoff

4672	Special Privileges Assigned

4688	Process Creation

4720	User Account Created

1102  security audit logs cleared 

6. Practical Investigation and Observations

I explored Windows Event Viewer and examined Security log entries.

Observations:

* Event ID 4624: Multiple successful login events were observed.
* Event ID 4625: One failed login attempt was identified. It was caused by my own incorrect login attempt.
* Event ID 4672: One event indicating special privileges assigned to a logon session was observed.

I also studied the purpose and security relevance of Event IDs 4634, 4688 and 4720.

7. SOC Analyst Perspective

A SOC analyst can use Windows Security logs to:

* Monitor authentication activities.
* Investigate repeated failed login attempts.
* Identify unusual account creation.
* Monitor privileged sessions.
* Investigate suspicious process execution.
* Correlate events to identify potentially malicious activity.

8. Conclusion

This hands-on exercise helped me understand how Windows Event Viewer records system and security activities. I gained practical exposure to Windows Security logs and learned how different Event IDs can support security monitoring and incident investigation.
